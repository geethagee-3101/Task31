# OTT Streaming Content Trend Analysis

## Project Overview
This project analyzes OTT streaming content from Netflix, Amazon Prime Video, and Disney+ Hotstar to identify trends in genre popularity, content ratings, release years, content types, and regional distribution.

## Objective
To perform Exploratory Data Analysis (EDA) and understand streaming content patterns using Python, SQL, and Excel.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- SQL
- Microsoft Excel
- Google Colab

## Dataset
The project contains 600 sample records with details such as:
- Content ID
- Title
- Platform
- Content Type
- Genre
- Country
- Release Year
- Content Rating
- Duration
